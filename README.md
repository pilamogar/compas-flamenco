# Compás flamenco

Metrónomo de compás para practicar bulerías, alegrías, sevillanas, fandangos de Huelva, tanguillos y rumba, con metrónomo, palmas, caja y guitarra.

Se abre desde GitHub Pages y se instala en el móvil desde el menú del navegador («Instalar aplicación» o «Añadir a pantalla de inicio»).

Las palmas, el cajón y la guitarra son grabaciones reales con licencia libre (CC0 y CC BY 3.0). Los créditos están en [sonidos/CREDITOS.md](sonidos/CREDITOS.md).

## App de Android (APK)

La carpeta `android/` envuelve la misma app web en una app nativa de Android (Android 6 o superior) que funciona sin conexión. Se compila sin Android Studio con `android/build.sh`, que explica qué necesita. La clave de firma no está en el repositorio: guárdala bien, porque las actualizaciones del APK tienen que firmarse con la misma.
